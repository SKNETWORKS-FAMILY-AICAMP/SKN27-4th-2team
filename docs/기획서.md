# 초보·기존 보호자를 위한 반려견 케어 Q&A 서비스

## 1. 프로젝트 개요

### 프로젝트 목표

강아지를 처음 키우는 사람과 이미 키우고 있는 보호자를 대상으로 반려견 케어 질문에 답변하고, 사용자의 성향·거주환경·생활패턴에 맞는 견종 정보를 제공하는 서비스를 구현한다.

### 핵심 사용자

* 강아지를 처음 키우려는 초보 보호자
* 이미 강아지를 키우고 있는 기존 보호자
* 강아지를 키워본 경험이 있는 사용자

### 핵심 차별점

* 유튜브 자막 기반 반려견 케어 지식과 AKC 견종 데이터를 RAG로 연결
* 근거 기반 반려견 케어 Q&A 제공
* 사용자 성향·거주환경·생활패턴 기반 견종 추천 제공
* AKC 견종 데이터 외에도 초보 보호자 가이드 데이터를 함께 활용

### 최종 결과물

* 반려견 케어 Q&A
* 견종별 특징 검색
* 사용자 성향 기반 견종 추천
* 초보 보호자 가이드
* 입양 준비도 테스트가 포함된 웹페이지

### 추후 확장 방향

유기견 추천 기능은 현재 핵심 기능이 아닌 부가 기능으로 두고, 추후 사용자 성향 기반 견종 추천 결과와 실제 유기견 데이터를 연결하는 방향으로 고도화한다.

### 사용자 입력 예시

* 강아지를 처음 키우려면 무엇부터 준비해야 하나요?
* 원룸에 살고 하루 8시간 외출하는데 어떤 견종이 잘 맞을까요?
* 털빠짐이 적고 초보자가 키우기 쉬운 견종을 추천해주세요.
* 강아지가 혼자 있을 때 계속 짖는 이유가 뭔가요?
* 푸들은 초보자가 키우기 쉬운 편인가요?

## 4. 데이터 활용 방식

사용자 질문 또는 입력 조건은 LLM과 RAG를 통해 다음 방식으로 활용된다.

1. 사용자가 질문 또는 생활환경 정보를 입력한다.
2. LLM이 입력 내용을 분석하여 질문 유형을 분류한다.
3. 질문 유형은 다음 중 하나로 분류한다.

   * 반려견 케어 Q&A
   * 견종 특징 검색
   * 견종 추천
   * 입양 준비도 테스트
4. RAG는 유튜브 자막 기반 케어 문서와 내부 기준 문서를 검색한다.
5. AKC 견종 데이터는 견종별 특징 검색과 사용자 성향 기반 견종 추천에 활용한다.
6. 사용자 성향 기반 견종 추천에서는 다음 조건을 구조화한다.

   * 거주 형태
   * 외출 시간
   * 산책 가능 시간
   * 털 관리 가능 여부
   * 소음 민감도
   * 활동 성향
7. 구조화된 사용자 조건과 견종별 특성을 비교하여 적합한 견종 유형과 후보 견종을 추천한다.
8. LLM은 검색된 문서와 견종 데이터를 결합하여 초보자도 이해하기 쉬운 답변을 생성한다.
9. 답변에는 추천 이유, 주의사항, 근거 문서를 함께 제공한다.
10. 유기견 추천은 현재 단계에서는 부가 기능으로 설명하고, 추후 사용자 성향 기반 견종 추천 결과와 연결한다.

## 5. RAG 연결 구조

### RAG에 저장할 문서

RAG에 저장할 문서는 다음을 중심으로 구성한다.

* 반려견 케어 기준 문서
* 견종별 특징 문서
* 초보 보호자 가이드
* 사용자 성향별 견종 추천 기준 문서
* 생활환경별 추천 기준 문서
* 입양 준비도 체크리스트

### 데이터별 활용 방식

#### 유튜브 자막 데이터

Q&A 답변의 실전 케어 근거로 활용한다.

예시는 다음과 같다.

* 분리불안 대처 방법
* 짖음 문제 원인
* 산책 훈련 방법
* 입질 교정 방법
* 배변 훈련 방법
* 보호자가 피해야 할 행동

#### AKC 견종 데이터

견종 검색과 견종 추천의 기준 데이터로 활용한다.

예시는 다음과 같다.

* 견종별 성격
* 활동량
* 털 관리 난이도
* 훈련성
* 가족 친화성
* 초보자 적합도

#### 내부 기준 문서

LLM 답변 형식과 추천 기준을 안정적으로 유지하기 위해 사용한다.

예시는 다음과 같다.

* 초보 보호자 가이드
* 생활환경별 추천 기준
* 사용자 성향별 추천 기준
* 입양 준비도 체크리스트

### 답변 생성 시 주의사항

* 답변에는 사용자의 질문 또는 생활조건과 검색된 문서 내용이 어떻게 연결되는지 설명한다.
* 건강·질병 관련 질문은 수의사 상담이 필요하다는 안내를 포함한다.
* 견종 추천은 일반적인 견종 특성 기반 참고 정보이며, 실제 개체 성향과 다를 수 있음을 안내한다.

### RAG 처리 흐름

```text
[사용자 질문 또는 성향 입력]
  ↓
[LLM: 질문 유형·생활조건·선호 조건 추출]
  ↓
[Vector DB: 케어 문서·견종 추천 기준 문서 검색]
  ↓
[AKC 견종 데이터: 견종별 특징 비교]
  ↓
[필터링/점수화: 주거·활동량·관리 부담·초보자 적합도]
  ↓
[LLM: Q&A 답변 또는 추천 견종 결과 생성]
  ↓
[웹 UI: 답변·근거·견종 카드·주의사항 출력]
```

* 반려견 케어 Q&A 입력창 및 답변 출력 기능 구현
* 견종별 특징 검색 기능 구현
* 견종 카드 출력 기능 구현

#### 1차 MVP 결과물

* 기본 웹페이지
* Q&A 입력창
* AI 답변 출력 영역
* 견종 검색 기능
* 견종별 카드 UI

### 8-2. 2차 RAG 확장

2차 단계에서는 문서 기반 검색과 근거 기반 답변 생성을 구현한다.

#### 주요 작업

* 유튜브 자막 데이터 chunking 수행
* 초보 보호자 가이드 문서 chunking 수행
* 견종 추천 기준 문서 chunking 수행
* Chroma 또는 pgvector에 임베딩 저장
* 사용자 질문에 맞는 문서 검색 기능 연결
* 검색 근거를 답변 하단에 표시
* Q&A 답변 형식 통일

#### Q&A 답변 형식

```text
1. 핵심 답변
2. 이유
3. 행동 가이드
4. 주의사항
5. 참고 근거
```

#### 2차 RAG 결과물

* Vector DB 기반 문서 검색 기능
* 근거 기반 Q&A 답변
* 답변 하단 참고 근거 표시
* 초보자 친화형 답변 템플릿

### 8-3. 3차 견종 추천 기능 구현

3차 단계에서는 사용자 성향과 생활환경을 기반으로 견종 추천 기능을 구현한다.

#### 주요 작업

* 사용자 성향·거주환경·생활패턴 입력 폼 구현
* 사용자 조건 구조화
* AKC 견종 데이터와 내부 견종 추천 기준 비교
* 견종별 적합도 계산
* 추천 견종 유형 출력
* 후보 견종 출력
* 추천 이유 및 주의사항 출력
* 입양 준비도 테스트와 견종 추천 결과 연결

#### 사용자 조건 구조화 예시

| 조건       | 예시            |
| -------- | ------------- |
| 주거 형태    | 원룸, 아파트, 단독주택 |
| 외출 시간    | 하루 8시간 외출     |
| 산책 가능 시간 | 하루 30분        |
| 관리 가능 수준 | 낮음, 보통, 높음    |
| 털빠짐 민감도  | 낮음, 보통, 높음    |
| 짖음 민감도   | 낮음, 보통, 높음    |
| 활동 성향    | 조용함, 보통, 활동적  |

#### 견종 추천 결과 예시

```text
추천 견종 유형: 소형견 / 낮은 활동량 / 비교적 훈련성이 높은 견종

후보 견종:
1. 푸들
2. 비숑 프리제
3. 말티즈

추천 이유:
- 원룸 생활에 비교적 적합한 크기
- 초보 보호자도 관리하기 쉬운 편
- 털빠짐이 비교적 적은 편
- 훈련성이 높은 편

주의사항:
- 견종 특성은 일반적인 경향이며 실제 개체 성향과 다를 수 있음
- 장시간 외출 시 분리불안 예방 훈련이 필요함
- 산책 시간이 부족할 경우 실내 놀이와 에너지 소모가 필요함
```

#### 3차 결과물

* 사용자 조건 입력 폼
* 견종 적합도 계산 로직
* 추천 견종 카드
* 추천 이유 및 주의사항 출력
* 입양 준비도 테스트 연동
